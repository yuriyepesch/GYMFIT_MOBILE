GYMFIT_MOBILE

Descripción del proyecto

GYMFIT_MOBILE es un prototipo de aplicación móvil desarrollado como parte del proyecto GYMFIT del SENA, orientado a presentar información sobre clases deportivas, planes y acceso demostrativo de usuarios.

Objetivo

Desarrollar un prototipo móvil que permita al usuario visualizar las opciones de clases deportivas, planes disponibles y una interfaz de acceso mediante usuario y contraseña.

Tecnología utilizada

MIT App Inventor

Android

Programación visual mediante bloques

Funcionalidades

Pantalla principal de bienvenida.

Visualización de clases deportivas: Spinning, CrossFit y Yoga.

Visualización de planes: Básico, Premium y VIP.

Interfaz de acceso con validación demostrativa de usuario y contraseña.

Navegación entre pantallas.

Usuario de prueba

Usuario: admin

Contraseña: 1234

Nota: La validación de acceso es demostrativa y no está conectada a un sistema de autenticación externo ni a una base de datos.
